# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/skylooperr/skylooperr-portfolio.git
```

Move into the directory

```bash
cd skylooperr-portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
